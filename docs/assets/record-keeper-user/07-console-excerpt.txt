          <p>
            Every message is length-prefixed with a 32-bit unsigned integer in
            network byte order. An empty frame is a liveness probe and returns
            <code>PONG</code>. A non-empty frame is written to the Brotli
            decoder; the first accepted frame returns <code>ACK</code>.
